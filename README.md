# CyberAI 🛡️

**CyberAI** is an AI-powered cybersecurity assistant designed to make cybersecurity knowledge more accessible. Built using React, Vite, FastAPI, and Google's Gemini API, it helps users explore cybersecurity concepts, understand technical topics, and analyze uploaded documents.

## ✨ Features

- 🤖 **AI-Powered Chat:** Get responses to cybersecurity questions using Google Gemini.
- ⚡ **Streaming Responses:** View AI-generated answers as they arrive.
- 💬 **Chat History:** Create, manage, search, and revisit conversations.
- 📄 **Document Analysis:** Upload PDF, DOCX, and TXT files for AI-powered summaries.
- 🔎 **Semantic Search (RAG):** Retrieve relevant document sections to answer document-related questions.
- 📝 **Markdown Support:** Display structured explanations, tables, and code snippets.
- 🛡️ **Security-Focused Guidance:** Learn about ethical hacking, network security, SOC, SIEM, incident response, and secure coding.
- 📱 **Responsive Interface:** Use the application across desktop and mobile screen sizes.

## 🧰 Tech Stack

- **Frontend:** React, Vite, CSS
- **Backend:** Python, FastAPI
- **AI Model:** Google Gemini
- **Document Retrieval:** Embeddings and Retrieval-Augmented Generation (RAG)
- **Database:** SQLite
- **Document Processing:** PyPDF and python-docx

## 🎯 Project Goal

The goal of CyberAI is to provide an accessible learning and assistance platform for cybersecurity students, enthusiasts, and professionals.

## ⚠️ Disclaimer

CyberAI is an educational assistant. Always perform security testing only on systems you own or have explicit permission to test. AI-generated responses may require independent verification.

## 🚀 Getting Started

See the project setup instructions in this repository's README and deployment documentation. Configure your Gemini API key in the backend environment file before running the application.
